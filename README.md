# Missão Front-end

Um quiz interativo e responsivo para quem está começando no desenvolvimento web. Teste seus conhecimentos de HTML, CSS e JavaScript com perguntas de múltipla escolha, explicações e uma pontuação final.

## Como executar

O projeto não precisa de dependências nem de um processo de build:

1. Baixe ou clone este repositório.
2. Abra `index.html` no navegador.

Se preferir, use a extensão Live Server no VS Code para abrir o projeto em um servidor local.

## Como contribuir

Contribuições são bem-vindas! Para propor uma mudança:

1. Abra uma issue para descrever a ideia ou o problema, se ainda não houver uma.
2. Faça um fork do repositório e crie uma branch para sua alteração.
3. Faça a alteração e teste o quiz no navegador, incluindo a visualização em telas menores.
4. Envie um pull request com um resumo do que mudou e como foi testado.

Para adicionar ou corrigir perguntas, confira a lista `questions` em `script.js`. Cada pergunta deve incluir o tema, o enunciado, quatro alternativas, o índice da resposta correta e uma explicação.

## Tecnologias

- HTML
- CSS
- JavaScript sem dependências
